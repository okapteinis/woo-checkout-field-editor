# WooCommerce Checkout Field Editor

Checkout Field Editor (Checkout Manager) for WooCommerce - forked for custom development.

## About This Repository

This is a forked version of the WooCommerce Checkout Field Editor plugin (version 2.1.5) maintained for custom development purposes.

**Original Plugin:** [Checkout Field Editor for WooCommerce](https://wordpress.org/plugins/woo-checkout-field-editor-pro/)
**Original Author:** ThemeHigh
**Original License:** GPLv2 or later

## Description

WooCommerce Checkout Field Editor enables you to edit the default checkout fields of your WooCommerce platform, add, edit, hide, or delete the default fields, change labels, rearrange checkout fields, validate the checkout fields, add custom CSS classes, and more.

## Features

- Complete checkout field customization
- 20+ field types for classic checkout
- Compatible with Classic & Block Checkout
- Add, edit, remove, and rearrange fields
- Custom field validation
- Custom CSS classes support
- Developer-friendly custom hooks

## Version Information

- **Current Version:** 2.1.5
- **Requires WordPress:** 4.9+
- **Tested up to:** WordPress 6.8
- **Requires PHP:** 5.6+
- **WooCommerce Compatibility:** Latest versions

## Installation

1. Upload the plugin files to `/wp-content/plugins/woo-checkout-field-editor/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Configure checkout fields in WooCommerce > Checkout Form
